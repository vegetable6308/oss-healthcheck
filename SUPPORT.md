# Support

Use GitHub Discussions for setup questions, scoring interpretation, and ideas that are not yet actionable. Use the structured bug template for reproducible defects and the feature template for concrete maintainer use cases.

Please include the tool version, Node.js version, operating system, command, sanitized output, and a minimal public repository or fixture when possible. Remove secrets and private paths before posting.

Security vulnerabilities must follow SECURITY.md and must not be reported publicly. Maintainers do not provide private consulting or guaranteed response times for general support.
